Integración con Google Sheets

  1. Crea una nueva hoja en Google Sheets.
  2. Nombra la primera fila (Fila 1) exactamente en este orden:
    PAR | FECHA | HORA | TIPO | GATILLO | PIPS SL | PIPS TP | RATIO | MAX RATIO | RESULTADO | DURACIÓN | DIARIO | HORARIO | ¿CUMPLE PLAN? | OBSERVACIONES | PORCENTAJE | R NEGATIVO | R POSITIVO
  3. Ve a Extensiones > Apps Script.
  4. Borra el código que haya y pega el código de abajo.
  5. Haz clic en Implementar > Nueva implementación.
  6. Selecciona Tipo: Aplicación web.
  7. Configura:
    • Ejecutar como: Tú (tu correo)
    • Quién tiene acceso: Cualquiera
  8. Haz clic en Implementar y otorga los permisos correspondientes. Copia la URL de la aplicación web y pégala arriba.

Código para Google Apps Script

function doPost(e) {
try {
var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
var data = JSON.parse(e.postData.contents);
sheet.appendRow([
data.par,
data.fecha,
data.hora,
data.tipo,
data.gatillo,
data.pipsSl,
data.pipsTp,
data.ratio,
data.maxRatio,
data.resultado,
data.duracion,
data.diario,
data.horario,
data.cumple,
data.observaciones,
data.porcentaje,
data.rNegativo,
data.rPositivo
]);
return ContentService.createTextOutput(JSON.stringify({ "status": "success" }))
.setMimeType(ContentService.MimeType.JSON);
} catch (error) {
return ContentService.createTextOutput(JSON.stringify({ "status": "error", "message": error.toString() }))
.setMimeType(ContentService.MimeType.JSON);
}
}
